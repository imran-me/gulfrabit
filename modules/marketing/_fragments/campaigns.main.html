Where the spend is read from

The account id is the number beside your ad account in Ads Manager. Reading spend needs the ads_read permission, which a Conversions API token often does not carry — if the sync says so, generate a System User token in Business Settings and save it here. It is stored encrypted and never shown again.

To keep it current without pressing anything, add one line to cron on the server: 0 4 * * * cd <app> && php artisan marketing:ad-spend-sync

Spend Meta cannot see

A boosted post from the page, an influencer paid in cash, an ad from another account. Typed rows are kept exactly as entered, and a sync never overwrites them.
