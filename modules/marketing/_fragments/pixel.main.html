Your three keys from Meta

Copy each one from Meta Events Manager and paste it here. Saving writes the pixel into every page of the shop.

  1. 1

    Public

    A number of 15 or 16 digits. It is not a secret — every page of the shop carries it.

    Where to find it: Events Manager→thenData sources→thenyour pixel It is the number under the pixel’s name.

    Leave it empty to switch Meta tracking off on every page. The visitor counts on the Tracking screen pause too, because they come from the same events.

    Your pages carry pixel right now. Saving with this box empty switches it off.

  2. 2

    Secret

    A long secret code that starts with EAA. With it, the server tells Meta about visits and orders directly, so ad blockers cannot hide them.

    Where to find it: Events Manager→thenyour pixel→thenSettings→thenConversions API→thenGenerate access token

    No token saved yet.

    Stored encrypted. It is never shown again in full.

  3. 3

    Optional

    A short code like TEST12345. It lets you watch the shop’s events arrive in Meta while you test.

    Where to find it: Events Manager→thenyour pixel→thenTest events Meta shows it as test_event_code: TEST… with a Copy button. Pasting the whole line is fine.

    For 60 minutes after you save it, the shop’s visits show in Meta’s Test events tab. After that the server ignores the code by itself, so a forgotten test code can never hide real sales from your ads.
